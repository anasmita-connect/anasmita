# anasmita

92 entries from the supplied August 2026 UPI Applications table, with sourced intended audiences, product descriptions and joining requirements.

Static site. The frontend lives in `public/`:

- `data.js`: generated from the register and research files. Do not edit directly.
- `app.js`: app list, main-audience filters and map.
- `detail.js`: main intended audience, other audiences for specific products, requirements and source links.
- `sources.html`: searchable source directory, audience CSV and bibliography CSV.
- `research-data.json`: downloadable dataset generated by the build.
- `sources/upi-applications-2026-08.pdf`: supplied PDF. Its NPCI attribution has not been independently authenticated.

Audience records live in `research/audiences-*.json`. Every primary and secondary label has source IDs and a basis: `explicit` for stated positioning, `interpretation` for an editorial assessment of the cited positioning. Company sites and credible reporting can both support labels. Filters use only the primary audience; a teen feature does not turn a general app into a teen app. Young adults do not imply minors. Audience is separate from eligibility and is not a claim about actual user percentages.

`research/copy-*.json` supplies concise descriptions and product-specific requirements. Older `demographics-*.json` records remain as research history and provide additional eligibility evidence; measured user figures are no longer published as audience labels. `audience-study.json` contains the published dataset notes. Each source has a URL, publisher, check date and support note. Published transaction totals are preserved instead of recalculated from rounded components.

## Run locally

    npm run dev        # http://localhost:4321

After editing evidence:

    npm run build
    npm run check

## Deploy to Cloudflare

    npx wrangler login
    npm run deploy     # build, validate, publish static assets Worker
